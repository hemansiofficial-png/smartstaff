# RestoCare-inspired color theme

The Smart Staff Request prototype now uses a warm hospitality-focused palette inspired by the visual direction of [RestoCare](https://www.restocare.in/):

- **Primary / action:** `#F15A24` — warm orange for main actions and selected states
- **Deep text:** `#20262E` — strong charcoal for headings and brand text
- **Page background:** `#FFF8F3` — warm off-white canvas
- **Soft accent:** `#FFF0E7` — pale peach for chips, selected cards, and supporting panels
- **Borders:** `#F0E4DB` — soft warm neutral
- **Success states:** existing green treatment retained to distinguish confirmed/available states
- **Warnings:** warm amber treatment retained for incomplete requests

This is an adapted palette inspired by the reference site's hospitality/service context, not a claim that these are its exact CSS hex values. The app's layout and workflow are unchanged.
